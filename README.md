# FinStart

Plataforma web gratuita de educação financeira voltada para jovens de 16 a 30 anos, desenvolvida como Projeto Integrador e Extensionista de Bancos de Dados Relacionais (PUC-Campinas).

## Problema
O baixo conhecimento financeiro entre jovens dificulta a poupança e leva ao endividamento, principalmente na transição para o primeiro emprego ou para a vida universitária.

## Objetivo
Unir conteúdo educacional a ferramentas práticas, como simulador de orçamento e de juros compostos, comparação de investimentos e definição de metas.

## Tecnologias
HTML, CSS e JavaScript (com POO) no site; SQL (MySQL) para o banco de dados.

## ODS
ODS 4 (Educação de Qualidade) e ODS 8 (Trabalho Decente e Crescimento Econômico).
